# generate-subtitle：功能与使用场景

[English](../../skills/generate-subtitle/README.md) | 简体中文 | [返回仓库首页](../../README.zh-CN.md) | [Agent 指令](SKILL.md)

**目标是：几乎不再需要手动修正字幕。** 将本地转写、保守纠错和自动排版串起来，再持续积累你常用的产品名、专有名词和识别纠错记录，减少每次逐条改字、手调断句的工作。

把本地视频、音频或已有字幕交给 Agent，完成从转写、纠错到字幕交付的工作。适合录制后的口播、教程、访谈和播客：既能处理一个文件，也能将多段视频接成一份合集字幕，或把多台设备同时录制的多个音频文件对齐并分轨（适用于多人谈话分多个设备收音的场景）。需要时，还可以另存翻译字幕、提炼章节标题与重点花字、生成发布前内容复核清单。

## 典型使用方法

安装后，在 Agent 会话中使用以下提示词，将示例路径替换为自己的素材路径。

| 场景 | 可以这样说 |
| --- | --- |
| 口播 / 教程字幕 | 「用 generate-subtitle 给 `/path/to/video.mp4` 生成原语言字幕，纠正明显错字，统一产品名和术语，保留语气词，列出需要我确认的地方。」 |
| 多段视频合集 | 「用 generate-subtitle 处理 `/path/to/videos/` 中的多段视频，先列出顺序供我核对，再按同样顺序首尾接续，生成一份合集字幕。」 |
| 多人访谈 / 播客 | 「用 generate-subtitle 处理 `/path/to/audios/` 中每人一台设备同时录制的多个音频文件，先核对对齐结果和说话人映射，再输出总字幕和每人一份字幕。」 |
| 外语音视频 | 「用 generate-subtitle 给 `/path/to/interview.mp4` 生成英文原语言字幕；存疑内容确认后，再另存一份中文字幕。」 |
| 已有字幕翻译 | 「用 generate-subtitle 把 `/path/to/video.srt` 翻译成英文，保留原字幕，另存 `video.en.srt`，保持编号和时间轴不变。」 |
| 章节、花字与发布前复核 | 「用 generate-subtitle 处理 `/path/to/tutorial.mp4`，生成字幕；有存疑先交给我确认，再检查敏感或冒犯性内容，提炼章节小标题和关键重点花字。」 |

## 主要能力

- **本地转写，按语言与素材选择引擎。** 中文默认优先使用 **FireRedASR2S**，未安装时回退到 **FunASR**；中文单轨混音需要声纹分离时使用 FunASR。非中文或语言检测不确定时使用 **Whisper**。默认生成原语言字幕，只有明确要求时才翻译。模型首次使用可能需要下载；转写结果在本地缓存，输入和相关配置未变时可复用。
- **多段视频接续，多设备录音对齐。** 多视频按创建时间排序后接成一条时间轴；多台设备同时录制的多个音频文件根据声音对齐起点，并校正检测到的明显时钟漂移。处理前可用 `--dry-run` 核对顺序、偏移和轨道映射，结果写入 manifest。合集字幕对应按同样顺序首尾拼接的成片，剪掉片段后需要重新匹配时间轴。
- **按声道、设备或声纹分开说话人。** 一人一支麦、分别占左右声道时自动分轨；一人一台设备时按录音轨道分轨。结合适用时的串音抑制、重复清理和 Agent 跨轨互校，减少同一句话重复出现；总字幕中两人同时说话可合成上下两行。单轨混音的声纹分离目前限于中文 FunASR 路径，FireRedASR2S 和 Whisper 不提供声纹分离；同一设备轨里有多人时，也不能仅靠设备分轨区分他们。
- **保守纠错，保留口语风格。** 默认修正有把握的同音近音错字，结合术语表与上下文统一专有名词，保留语气词；没把握的地方列入待确认字幕。中文内容还会处理误识别的连续重复、年份写法和中英文间距；明确需要去水词时可选 `clean` 级别。中文专项规则不会直接套用到其他语言。
- **自动断句、排版与时间轴整理。** 按时间戳和停顿拆分字幕，保护英文单词、产品名及术语，整理重叠、过短或拖尾过长的条目。默认每行目标字宽为 16 个中文字符，普通英文和数字按半宽计；为保全术语可适度超宽，并非绝对的 16 字硬上限。
- **按需翻译、提炼章节与花字、复核发布内容。** 翻译可直接使用已有字幕，保留原文、编号、时间轴与说话人标记，另存目标语言版本。章节小标题和关键重点提示合在一份花字字幕中。内容复核从敏感信息、人身攻击、引起不适、冒犯性四类标出高 / 中 / 低风险，附原文、时间位置和处理建议，供人工决定删改。

## 把识别错误积累到术语表

**遇到识别错误，纠正当前字幕的同时，提醒 Agent 把“错误写法 → 正确写法”存入术语表，作为后续可复用的纠错语料。** 产品名、行业术语和反复出现的同音误识别尤其适合积累；有歧义的词要附上适用语境，避免在其他内容里误改。

可以直接说：「这里的‘卡索’应该是‘Cursor’，请修正字幕，并将这条纠错存入本地项目的术语表；以后处理同类内容时也加载这份表。」项目术语表可通过 `--glossary` 加载，与 skill 自带的 `glossary.txt` 一起使用。

围绕同一主题使用几次，并把确认过的常见错误持续补进术语表，就能逐步减少重复改字，朝着**几乎不再需要手动修正字幕**的目标靠近。改进来自后续纠错时复用这些记录；实际效果仍取决于收音质量、内容和术语覆盖程度，存疑字幕继续按提示听原声确认。

## 会得到哪些文件

以下以 SRT 输出为例；分轨、翻译、花字和复核文件按素材及所选功能生成。

| 文件 | 用来做什么 |
| --- | --- |
| `<名字>.srt` / `<名字>.raw.srt` | 纠错后的总字幕与 ASR 原文对照，便于导入剪辑器及回看修改 |
| `<名字>.spkN.srt` / `<名字>.spkN.raw.srt` | 每位说话人的字幕及分轨原始对照，便于分别校对或使用 |
| `<名字>.uncertain.srt` | 没把握的文字及候选改法，按时间码跳转听原声确认 |
| `<名字>.dedupe.md` / `<名字>.manifest.json` | 去重修改对照，以及源文件顺序、时间偏移、轨道映射等记录 |
| `<名字>.en.srt` 等 | 单独保存的译文字幕，语言代码随目标语言变化 |
| `<名字>.highlights.srt` | 章节小标题和关键重点花字，可导入剪辑器叠加使用 |
| `<名字>.review.srt` / `<名字>.review.md` | 可定位的内容复核字幕，以及风险说明与处理建议清单 |

## 与视频剪辑软件配合使用

生成的 SRT 文件带有字幕文字和时间码，可以在支持 SRT 导入的剪辑软件中拖入，或通过“导入字幕”入口加载，再继续编辑文字和样式。具体的导入方式、多字幕轨支持和样式选项以所用软件为准。

1. **先对齐素材时间轴。** 单文件字幕对应原素材的时间位置；多段视频按 manifest 中的顺序首尾拼接；多设备录音按记录的偏移对齐。导入字幕时保持相同的时间起点，多设备录音还需与画面同步，可在开头、中间和结尾试听检查。
2. **导入总字幕，或分别导入各 speaker 的字幕。** 使用 `<名字>.srt` 可以统一设置整片对白样式；需要区分人物时，可将 `<名字>.spk1.srt`、`<名字>.spk2.srt` 等分别拖入支持多字幕轨的工程，为每人设置不同的颜色、位置或样式。这些文件共用时间轴，应保留各自原始时间码；总字幕和分人字幕通常选一种显示，避免同一句话重复叠加。
3. **导入章节与花字，继续设计样式。** 将 `<名字>.highlights.srt` 作为额外的字幕层导入，里面同时包含带 `【N】` 标记的章节小标题和关键重点花字。可以分别选中这些条目，调整字体、字号、颜色、描边、位置和显示时长；软件支持时还可加背景或入出场动画。章节标题可放大居中，重点花字可放在对白字幕上方，按画面留白调整。
4. **用辅助字幕定位需要核对的地方。** 将 `.uncertain.srt` 临时导入，逐条跳转听原声，把确认后的文字改回正片字幕；将 `.review.srt` 配合 `.review.md` 使用，定位需要删改的内容。完成后隐藏或移除这些辅助字幕，导出前只保留要给观众看的字幕层。

**实际流程是：转写与纠错 → 有存疑时人工听原声确认 → 按需翻译、内容复核和花字。** 自动排版能减少手调工作，但仍需核对存疑文字、花字和复核结果。花字交付的是字幕文字与时间码，视觉样式在剪辑器中设置。

ASR 在本地运行；纠错、翻译、花字和复核由当前 Agent 会话接手完成，使用云端模型时相关文字会进入模型上下文。完整参数、依赖和操作步骤见 [SKILL.md](SKILL.md)，多语言支持与限制见[多语言转写与翻译](references/multilingual.md)。
